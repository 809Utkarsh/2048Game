# 2048 Game

A browser-based implementation of the popular 2048 puzzle game using **JavaScript**, **HTML**, and **CSS**, built with **Vite** for fast development.

---

## 🎮 Game Overview

2048 is a single-player sliding block puzzle game. The objective is to slide numbered tiles on a grid to combine them and create a tile with the number 2048.

**Features:**
- Responsive 4x4 grid
- Keyboard and swipe controls
- Smooth tile animations
- Tracks score
- Merge logic with increasing tile values

---

## ⚡ Technologies Used

- **JavaScript** – Game logic
- **HTML / CSS** – UI and styling
- **Vite** – Development server and bundler
